# HighTempTation 五层优化清单

> 备忘 — 按优先级从 L1（最基础）到 L5（最复杂），逐步推进。

---

## L1 — 数据模型

| # | 项目 | 说明 | 优先级 |
|---|------|------|--------|
| 1.1 | **偏态分布建模** | 当前假设温度预报误差服从正态分布，实际气温分布有左/右偏态。引入 Skew-Normal 或 GEV 分布改进概率估计 | P1 |
| 1.2 | **集合预报集成** | Open-Meteo 返回5个模型（best_match, icon_seamless, gfs_seamless, gem_seamless, jma_seamless）。用加权平均（按历史精度）替代简单平均 | P1 |
| 1.3 | **模型精度追踪** | 记录每个模型/每个城市的 MAE 和偏差，建立模型精度矩阵，动态调整集成权重 | P2 |
| 1.4 | **温度-价格映射函数** | 当前用 RSI 近似模型概率。改为直接建模 `P(YES) = f(forecast_mu, forecast_sigma, bucket_threshold)` | P2 |

## L2 — 执行成本

| # | 项目 | 说明 | 优先级 |
|---|------|------|--------|
| 2.1 | **订单簿深度感知** | 下单前查询 Polymarket 订单簿深度，计算 VWAP 滑点。深度不足时拆分订单 | P1 |
| 2.2 | **限价单策略** | 当前全部市价单。改为限价单 + 超时转市价，减少滑点损失 | P1 |
| 2.3 | **Gas 费优化** | Polygon 交易 Gas 波动大。设置 Gas 上限 + 批量交易合并 | P2 |
| 2.4 | **流动性路由** | 比较 Polymarket CLOB vs LP 池的价格差异，选择最优路径 | P3 |

## L3 — 组合风险

| # | 项目 | 说明 | 优先级 |
|---|------|------|--------|
| 3.1 | **城市相关性矩阵** | 计算各城市温度的相关性（东京/大阪/札幌高度相关，东京/纽约低相关），控制集中度风险 | P1 |
| 3.2 | **风险平价仓位分配** | 按城市-温度区间组合的波动率分配仓位，替代当前的均分 $1/仓 | P2 |
| 3.3 | **尾部风险对冲** | 持有极端温度事件的价外期权保护。例如同时买入 5% 概率的 YES+NO 对冲黑天鹅 | P3 |
| 3.4 | **VaR / CVaR 限制** | 每日 CVaR(95%) 不超过账户 2%。计算组合 VaR 并设置硬性风控线 | P3 |

## L4 — 时间衰减

| # | 项目 | 说明 | 优先级 |
|---|------|------|--------|
| 4.1 | **距结算 <2h 强平** | 对已浮盈仓位，距结算不足 2 小时时强制平仓（当前仅阻止开仓） | P1 |
| 4.2 | **时间价值衰减模型** | 建模 `theta = dP/dt`，温度每接近结算 1 小时，期权价值衰减率 | P2 |
| 4.3 | **结算前波动率扩张** | 结算前 6h 通常波动率放大（信息 influx），调整仓位规模和止盈距离 | P2 |
| 4.4 | **隔夜持仓管理** | 凌晨 0-6 点流动性枯竭时段减仓或只平不开 | P3 |

## L5 — 实盘工程

| # | 项目 | 说明 | 优先级 |
|---|------|------|--------|
| 5.1 | **数据库持久化** | SQLite/PostgreSQL 存储：交易记录、信号日志、账户快照。支持回放复盘 | P1 |
| 5.2 | **Telegram 告警** | 开仓/平仓/风控触发时推送 Telegram Bot 消息（含截图） | P1 |
| 5.3 | **DRY_RUN / LIVE 开关** | 环境变量切换：模拟模式只读市场不下单，实盘模式全功能 | P1 |
| 5.4 | **Web 操作面板** | 简单 Flask/FastAPI 面板：查看持仓/手动平仓/修改参数 | P2 |
| 5.5 | **自动重启 + 健康检查** | PM2 自动重启 + `/health` 端点 + 15 分钟无心跳告警 | P2 |
| 5.6 | **每日报告生成** | 每天 UTC 0 点自动生成回测式日报（PnL/胜率/持仓/回撤） | P3 |
| 5.7 | **A/B 测试框架** | 同时运行 v1(生产) + v2(实验)，对比信号质量 | P3 |

## L6 — 高阶优化（第二波，已落地于 `tools/hightemptation_live/highopt/`）

| # | 项目 | 实现 | 说明 |
|---|------|------|------|
| 6.1 | **订单簿微观结构** | `highopt/microstructure.py` | LOB 形状建模、深度斜率检测、Square-Root Law 冲击预估（ΔP=k·σ·√(Q/V)）、VPIN 逆向选择过滤 |
| 6.2 | **跨市场/跨期套利** | `highopt/arbitrage.py` | 桶分割（ΣYES≈1）、相邻桶 Put-Call Parity、合并桶可加性、期限结构倒挂/升水、多平台价差 |
| 6.3 | **ML 残差学习** | `highopt/ml_residual.py` | LightGBM/XGBoost（降级 sklearn/均值）修正物理模型残差、在线学习（滚动窗口）、NLP 情绪增强 |
| 6.4 | **订单状态机 FSM** | `highopt/order_fsm.py` | Client Order ID 幂等、幽灵订单防护（UNKNOWN 态）、部分成交累计、仓位对账 |
| 6.5 | **Walk-Forward 回测** | `highopt/walk_forward.py` | Point-in-Time 数据（无前视断言）、成本敏感性扫描、夏普/Calmar 稳定性 |
| 6.6 | **混沌工程** | `highopt/chaos.py` | 故障注入（延迟/404/500/丢包/余额突变）、熔断器 CLOSED→OPEN→HALF_OPEN→CLOSED、5 场景验证 |
